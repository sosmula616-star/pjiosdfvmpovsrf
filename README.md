# 🛡️ Musicium Staff Bot & Web Dashboard

Комплексный Discord Стафф-бот и современная веб-панель управления сообществом для музыкального бота **Musicium**.

Включает в себя:
- 🔨 **Продвинутую систему модерации** (Временные и перманентные баны, текстовые и голосовые муты с таймерами, система предупреждений/варнов)
- 🚀 **1-Click Авторазвертку сообщества** (Русскоязычные и англоязычные категории, чаты, правила на двух языках, гайд по командам бота)
- 🛡️ **Систему Антикраша (Anti-Crash / Anti-Nuke)** с гибкими лимитами в минуту и автоматическим карантином/баном злоумышленников
- 🌐 **Премиум Веб-панель управления** (Настройка прав ролей по каналам, лимиты антикраша, таблицы активных наказаний, база варнов)
- 📋 **Выделенные журналы аудита** по всем 6 категориям как в Discord, так и на сайте

## ⚡ Быстрый старт

### 1. Настройка переменных окружения
Откройте файл [`.env`](file:///e:/Musicium%20staff/.env) и укажите ваши данные:
```env
DISCORD_TOKEN=ваш_токен_бота_с_discord_developer_portal
CLIENT_ID=id_вашего_приложения
GUILD_ID=id_вашего_сервера_для_быстрого_теста_команд

HOST=0.0.0.0
PORT=3000
DASHBOARD_PORT=3000
DOMAIN=staffbotekssss.bothost.tech
ADMIN_PASSWORD=ваш_надежный_пароль_администратора
SESSION_SECRET=musicium-staff-super-secret-key-2026
```

> **Важно:** В [Discord Developer Portal](https://discord.com/developers/applications) в разделе **Bot** включите все **Privileged Gateway Intents**:
> - `Presence Intent`
> - `Server Members Intent`
> - `Message Content Intent`

### 2. Запуск
```bash
npm start
```

После запуска в консоли отобразится:
- Локальная веб-панель: `http://localhost:3000`
- Хостинг / домен: `http://staffbotekssss.bothost.tech:3000` (или `https://staffbotekssss.bothost.tech`)
- Статус подключения Discord бота

## 🌐 Веб-панель управления

1. Перейдите в браузере по адресу `http://staffbotekssss.bothost.tech:3000` (или `http://localhost:3000`).
2. Введите пароль администратора, заданный в `.env`.
3. Доступные разделы:
   - **Обзор & Статус**: статистика сервера, статус щита антикраша.
   - **Права ролей**: выбор роли и настройка разрешений (Просмотр, Сообщения, Файлы, Голос, Говорить, Управление) для каждого канала с мгновенным сохранением в Discord.
   - **Антикраш лимиты**: ползунки допустимых действий в минуту (удаление/создание каналов, ролей, баны, кики, вебхуки), выбор наказания (Карантин, Бан, Кик) и вайтлист.
   - **Модерация & Варны**: список активных временных банов и мутов с возможностью досрочного снятия, база варнов и форма для быстрых действий с сайта.
   - **Журнал аудита**: фильтрация логов по 6 категориям и строке поиска.
   - **Автонастройка**: развертывание структуры сервера в 1 клик.

## 🔨 Слэш-команды модерации

- `/profile [target]` — Просмотр карточки профиля участника (кастомный фон/баннер, уровень, прогресс-бар XP, точное время в голосовых, сообщения, значки).
- `/leaderboard [type]` — Рейтинг сервера по Опыту (`xp`), времени в голосовых (`voice`) или сообщениям (`messages`).
- `/setprofile [banner_url] [bio] [title]` — Настройка своего фона (прямая ссылка на картинку), статуса "О себе" и титула прямо в Discord.
- `/setup-server` — Автоматически создает категории, каналы, роли, правила (RU & EN) и подключает логи.
- `/ban <target> [duration] [reason]` — Бан на время (`10m`, `2h`, `1d`, `7d`, `30d`, `perm`) или навсегда. Автоматически разбанивает по истечении срока.
- `/unban <user_id> [reason]` — Досрочная разблокировка по ID.
- `/mute <target> <type> [duration] [reason]` — Мут текстовый (Discord тайм-аут) или голосовой (Voice Mute).
- `/unmute <target> [type] [reason]` — Снятие текстового или голосового мута.
- `/warn <target> <reason>` — Выдача официального предупреждения.
- `/warns <target>` — Просмотр истории предупреждений пользователя.
- `/clearwarns <target> [warn_id]` — Удаление одного или всех варнов.
- `/kick <target> [reason]` — Исключение участника с сервера.
- `/help` — Справка по всем возможностям стафф-бота.

## 🎨 Система профилей, фонов и уровней

* **Учет времени в голосовых комнатах**: Бот автоматически отслеживает каждую минуту нахождения участников в голосовых каналах.
* **Система опыта и уровней**: XP начисляется как за общение в текстовых каналах (с кулдауном от спама), так и за прослушивание музыки в войсе.
* **Кастомные фоны (баннеры)**: Участники и администраторы могут выбирать фон из встроенной галереи (Synthwave, Cyberpunk, Nebula, Vinyl, Equalizer, Lo-Fi) или устанавливать любой свой URL изображения.
* **Веб-редактор и Лидерборд**: На сайте доступна отдельная вкладка **"Профили & Уровни"**, где можно просматривать живую интерактивную карточку любого участника, переключать топы (по XP, войсу, сообщениям) и редактировать оформление.

## 🚀 Деплой на хостинг

База данных хранится локально в папке `data/database.json`, поэтому для переноса на хостинг или VPS достаточно скопировать проект и запустить его.

1. **Переменные окружения для хостинга**:
   Сервер автоматически поддерживает порт хостинга (`PORT` или `DASHBOARD_PORT`) и слушает все сетевые интерфейсы (`HOST=0.0.0.0`).
2. **Запуск через PM2 на VPS/Хостинге**:
   ```bash
   npm install -g pm2
   pm2 start index.js --name musicium-staff
   pm2 save
   pm2 startup
   ```
3. Файл базы данных `data/database.json` сохраняет все данные, настройки антикраша, активные баны/муты, логи и уровни участников.

## 📋 6 Журналов аудита

При автонастройке создается отдельная защищенная категория **📋 ЖУРНАЛ АУДИТА** со следующими каналами:
1. `🚨│логи-антикраш` — Тревоги превышения лимитов и подозрительной активности.
2. `🔨│логи-модерации` — Баны, разбаны, муты, варны, кики.
3. `💬│логи-сообщений` — Редактирование и удаление сообщений.
4. `👥│логи-участников` — Входы, выходы, добавление и снятие ролей.
5. `🛠️│логи-каналов-ролей` — Создание, удаление и редактирование каналов и ролей.
6. `🎙️│логи-голосовых` — Вход, выход, перемещение по каналам, серверный мут.
